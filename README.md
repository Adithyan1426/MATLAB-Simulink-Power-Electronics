# MATLAB & Simulink – Power Electronics

A collection of MATLAB and Simulink simulations exploring power electronics, power conversion, switching circuits, and control techniques. This repository documents my practical learning, circuit modeling, waveform analysis, and simulation experiments in electrical engineering.

## Topics Covered

- DC-DC converters
- Buck and Boost converters
- AC-DC rectifiers
- Controlled rectifiers
- Three-phase converters
- Pulse Width Modulation (PWM)
- MOSFET switching characteristics
- Gate driver circuits
- Bootstrap circuits
- Optocoupler circuits
- Power conversion and switching analysis

## Tools & Software

- MATLAB
- Simulink
- Simscape Electrical (where applicable)

## Simulations

Each simulation is intended to include, wherever applicable:

- Circuit/model files
- Simulation parameters
- Input and output waveforms
- Voltage and current analysis
- Switching behavior
- Brief explanation of circuit operation
- Observations and conclusions

## Objectives

- Understand the operation of power electronic converters.
- Analyze switching devices and their behavior.
- Study PWM-based switching and control.
- Explore power conversion circuits using simulation.
- Develop practical understanding of electrical engineering concepts.

This repository is continuously updated as new circuits are modeled, simulated, and analyzed.
